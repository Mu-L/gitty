## Why it matters

**Why do this?**

Gitty had grown past what a cold start could afford — xterm, highlight.js and markdown-it were all parsed before the first frame even though most sessions never touch them. And the interface was English-only while the README already described a window the four-pane framing no longer matched.

**What problem does it solve?**

Startup waited on libraries most sessions never use, and the things a history browser needs daily — push/pull, image previews, full screen — were missing. Strings hardcoded in JSX made any translation impossible, and a scrolled diff lost its place on reload.

**What does it affect?**

A faster-to-open Gitty that pushes and pulls, previews images, goes full screen pane by pane, and speaks nine languages chosen at runtime — with the lazy-loading contract, the i18n policy, and the new README structure all documented. Released as 0.1.3.
