## Why it matters

**Why do this?**

The day's plan (`ref/plan/2026-08-15-repotab-split.md`) is one half of it; the
other is a steady pass over the seams an external review left rough. Reading a
file at a commit worked, but nothing showed *how* it grew; the agent command
was a single stored string with no way back; the branch menu hung off a static
label that could disagree with the name it described.

**What problem does it solve?**

The symbols outline turns a file's structure into something skimmable without
opening an IDE, and the per-commit lengths make File History answer "when did
this grow?" from the list alone. An in-repo link was dead weight in a markdown
preview — now it navigates the way a link should. The command picker makes the
hand-over repeatable instead of a guess, and the empty-index fix means a first
commit can be staged entirely by the agent.

**What does it affect?**

`symbols.ts` is deliberately pure string work so `test/symbols.test.ts` can pin
it — a wrong outline does not throw, it draws a wrong tree. The agent-command
shape is recorded in CLAUDE.md so the constraints (the head of the MRU list is
the current command, forgetting is confirmed in main) survive the session. The
manual's move to `ref/readme/` with the English file as the only source of
truth is the doc half of shipping 0.1.7.
