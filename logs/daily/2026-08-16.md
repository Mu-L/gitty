## Why it matters

**Why do this?**

Two names for two different things had been sharing one word: what is
uncommitted and the whole directory on disk were both "Working Tree", on screen
and in the comments. Meanwhile the headers had accumulated one control per
feature, the search box only took a pattern, and CLAUDE.md had grown past the
40k characters the harness will read — most of it description rather than
instruction.

**What problem does it solve?**

The rename plus the title-as-a-switch makes the top-left pane say what it is
listing and offer the other view in the same place. The query syntax turns
repository search into something that can be narrowed without leaving the box,
and the icons make a long file list skimmable by shape and hue rather than by
reading every extension. Folding the rare actions behind ⋯ gives the common
ones room.

**What does it affect?**

0.1.8 ships all of it. `query.ts` is pure string work with its own test file
because a wrong parse is silent — it returns the wrong lines rather than
throwing. The CLAUDE.md split is the durable half: rules in one file, design in
`ref/spec/*` named for the subsystem, so an agent reads the constraint it needs
without the 27k characters of background that were pushing the file past what
gets loaded at all.
