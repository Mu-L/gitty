## Why it matters

**Why do this?**

The common reading actions — finding a word, copying a selection, seeing the
About facts, opening another repository — each forced a detour or simply were
not there: a rendered markdown page had no way to be searched, a terminal's
Ctrl+C could not copy, and the About box was a native dialog whose text could
not be clicked. The blame pane was plain text against a wall of similar rows,
and every date on screen was stuck in the machine's zone.

**What problem does it solve?**

Ctrl+F now searches the rendered text of whatever the right-hand pane shows,
with highlights that survive React's rewrites and an HTML preview searched
inside its own frame. Ctrl+Shift+C copies from the diff, a file, a rendered
document and a terminal alike without being eaten by the shell's interrupt.
About shows the true version and build time with a live link. Blame reads by
hue and date, the clock can be set to any zone, and a + in the title bar opens
a repository without hunting through the menu.

**What does it affect?**

These are cross-view capabilities: find and copy apply to every pane, so their
behaviour no longer changes as focus moves. Find draws matches with the CSS
Custom Highlight API and the new strings — the About facts, the find strip —
thread through all nine message tables, while timezone handling joins the
existing time module rather than the translation tables. The release 0.1.5
ships on top of all of it.
