## Why it matters

**Why do this?**

Both fixes are the same kind: a feature that had shipped and did not actually
work on screen. Added-line numbers that cannot be seen are worse than none, and
a rename that only two of three places honour reads as a bug in the rename.

**What problem does it solve?**

The markdown gutter now marks what the diff marks, including a fence whose body
changed but whose opening line did not — the case the first implementation was
blind to. The recent list names a repository the way the rest of the window
does.

**What does it affect?**

`MarkdownPane`'s `changedIn` is the one place a block's span is compared with
the diff, so a fourth kind of block gets the mark for free. `App.tsx` reads the
recent list through `tabLabel`, which is where tab naming already lives.
