## Why it matters

**Why do this?**

0.1.4 is where Gitty's browsing grew past the work tree. Until it, the app
showed the current tree and its diffs and little else: no way to move between
commits and come back, no way to follow a single file through history, no way
to narrow the log to the commits that matter. Gource gives that history a
visual entry point, and finishing the message tables means every string on
screen now goes through translation.

**What problem does it solve?**

The bottleneck was browsing. Finding a commit meant scrolling and reading, and
with no back button, clicking one lost the place you were looking at. Blame and
file history let the diff pane carry more than one dimension of a file, and the
line counts let the file list itself say how big a change is.

**What does it affect?**

Together these make Gitty's core loop: commit list → file tree → diff, with
navigation, filtering and context actions at every step. The test scaffolding
laid down here is the safety net everything after it is built on.
