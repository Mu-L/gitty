## Why it matters

**Why do this?**

Reading git history day to day is awkward: the command line shows diffs through too narrow a window, and GUI clients leave the terminal outside. Switching back and forth breaks the train of thought. What was wanted is a local tool that puts all four things — which files changed, how they changed, the surrounding history, and a shell to type into — on one screen.

**What problem does it solve?**

The point is browsing, not operating. Looking at another branch's history should not force a checkout; seeing the whole tree at a commit should not require a stash; reading a markdown change should not mean reading raw diff text. And when several repositories are open at once, each needs to keep its own view state and its own shells.

**What does it affect?**

An installable desktop app (0.1.1) with a global command and a desktop launcher: four-pane layout, syntax highlighting, markdown preview, tabs and splittable terminals all working, with README, CHANGELOG and CLAUDE.md as the base for later work.
